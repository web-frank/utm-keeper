# utm-keeper

[English](README.md) · **Русский**

Хранит метки кампаний между страницами и переносит их в каждую форму.

**654 байта min+gzip** (1 156 байт minified ESM). Без зависимостей в рантайме. ESM, CommonJS и типы TypeScript.

```js
import { utmKeeper, get } from 'utm-keeper';
const stop = utmKeeper();
console.log(get()); // { utm_source: 'newsletter', ... }
```

Запускайте после того, как доступен DOM. Сохраняет `utm_source`, `utm_medium`, `utm_campaign`, `utm_term`, `utm_content`, `utm_id`, `gclid`, `yclid` и `fbclid` из строки запроса. Новый заход с непустыми параметрами замещает сохранённый набор; страницы без меток его сохраняют. Метки хранятся в localStorage, пока не заменены или не очищены. `get(options?)` возвращает свежий объект.

Текущие и динамически добавленные формы получают скрытые поля. Слушатель на перехвате submit покрывает формы, созданные прямо перед отправкой. Существующие скрытые поля обновляются; видимые — сохраняются. Вызовите `stop()`, чтобы отключить наблюдатели и слушатели. Если хранилище заблокировано, метки остаются в памяти только для этой страницы. Инициализация безопасна при SSR.

| Опция | По умолчанию | Поведение |
| --- | --- | --- |
| `storageKey` | `'utm-keeper'` | ключ localStorage; передайте ту же опцию в `get()`. |

## Чего не делает

Не отправляет данные, не идентифицирует посетителей, не назначает атрибуцию, не управляет согласием, не декорирует ссылки и не обращается к cross-origin хранилищу. Не достаёт формы внутри shadow root или iframe, не перехватывает прямые вызовы `form.submit()` и не задаёт срок годности меткам. Подключайте согласно политике согласия вашего сайта.

## Разработка

`npm ci`, `npm test`, `npm run build`. Сборка печатает размер minified ESM и gzip (Node 22, уровень 9), без tree shaking. MIT © 2026 Daniel Raskopin. Самостоятельный вынос паттерна декорации форм из трекера, с локальным хранением меток кампаний.

## Живое демо

Откройте [`demo/index.html`](demo/index.html) прямо в браузере. Самодостаточный файл включает библиотеку и работает офлайн, без сервера и сборки. `npm run build` обновляет встроенную библиотеку из исходника.
